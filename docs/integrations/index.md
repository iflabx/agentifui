# Agent Integrations

AgentifUI connects to existing Agent services; it does not build or host Agents.

- [Dify](../DIFY-INTEGRATION.md): supported Service API applications and compatibility limits.
- [LangChain](../LANGCHAIN-INTEGRATION.md): the service contract and optional human-input profile.
- [AG-UI](../AGUI-INTEGRATION.md): shared interaction events and supported backend mappings.
- [Generation governance](../AGENT-GOVERNANCE.md): authorization, moderation,
  admission, submission identity and persistence responsibilities.

For administrator-facing setup, use the
[provider and application guide](../ADMIN-GUIDE.md#3-configure-a-provider-and-application).
For extending the implementation, use the [developer guide](../DEVELOPMENT.md).
